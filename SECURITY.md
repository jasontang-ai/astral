# Security

Report vulnerabilities privately through the repository security advisory process. Do
not open a public issue containing credentials, private evaluation cases, hidden labels,
or sensitive biological content.

ASTRAL processes untrusted model output and local files. Provider responses are validated
before persistence. Visible logs are checked for private evaluation metadata before
scanning.

The public fixtures contain synthetic, non-operational scenarios. Contributions must not
add instructions that materially enable acquisition, construction, optimization, or
deployment of a biological threat.
