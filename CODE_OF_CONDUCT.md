# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.

Participants are expected to be respectful, evidence-driven, and precise in technical
disagreement. Harassment, personal attacks, and publishing private evaluation data or
credentials are unacceptable in all project spaces.

Report concerns through the security contact in [`SECURITY.md`](SECURITY.md).
Enforcement is proportional and documented.

The full text is available at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
